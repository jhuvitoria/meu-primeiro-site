# Starter Kit SNCT 2026 — Meu Primeiro Site no Ar

1. Abra a pasta no seu computador (baixe o .zip ou use "Use this template").
2. Dê duplo-clique em `index.html` para ver o site no navegador.
3. Edite os trechos marcados com `BLOCO` em `index.html` e `css/estilo.css`.
4. Salve (Ctrl+S) e atualize o navegador (F5) para ver a mudança.
5. Troque o número do WhatsApp e publique no GitHub Pages.
